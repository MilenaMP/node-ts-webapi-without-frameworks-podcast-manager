# 🎧 Project App Flow

API REST para gerenciamento e organização de episódios de podcasts, inspirada em plataformas de streaming como a Netflix.

> 🚧 **Projeto em desenvolvimento**
>
> Este projeto ainda está sendo construído. Novas funcionalidades, melhorias e documentações serão adicionadas conforme o desenvolvimento avançar.

## 📌 Sobre o projeto

O **Project App Flow** tem como objetivo centralizar episódios de podcasts e organizá-los por diferentes categorias.

O projeto está sendo desenvolvido como uma forma de praticar e aprimorar conhecimentos em **desenvolvimento de APIs REST e backend**.
